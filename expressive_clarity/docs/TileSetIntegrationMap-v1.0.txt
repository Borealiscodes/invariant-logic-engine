## 2. Canonical → Refinement → Derivative  
### **Unicode Ledger Tile**  
- Canonical truth glyph  
- Defines the ledger identity  
- No palette semantics  
- No compression  

### **Dark‑mode Ledger Tile**  
- Reflective‑basin readability  
- NDH night palette  
- Registry band + caption  

### **Ledger Microtile**  
- Compressed emblem  
- Minimal truth surface  
- Used for indexing and compact UI

These three form the **tile triad**.

---

## 3. Composite Layer  
### **LedgerTileSet‑v1.0.json**  
- Machine‑readable registry  
- Lists canonical, refinement, derivative tiles  
- Provides cross‑refs to provenance indexes  
- Defines tile ordering  

### **LedgerTileSetPNG‑v1.0.png**  
- Visual composite  
- Three‑column layout  
- Transparent background  
- Registry band + caption  

### **LedgerTileSetUnicode‑v1.0.txt**  
- GitHub‑safe Unicode composite  
- Mirrors PNG layout  
- No palette rendering  

These three form the **composite triad**.
